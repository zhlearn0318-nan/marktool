# Frontend assets

- `content-landscape.jpg`: downloaded from `https://picsum.photos/seed/tracemark-landscape/1920/1080`. Used as illustrative content in the TraceMark landing page, not as a user upload or a real detection result. Source service: https://picsum.photos/ (Unsplash photography).
- `Satoshi-Variable.woff2`: Satoshi variable, normal, weights 300–900. Retrieved through Fontshare's Satoshi stylesheet: `https://api.fontshare.com/v2/css?f[]=satoshi@variable&display=swap`. Typeface and usage terms: https://www.fontshare.com/fonts/satoshi and https://www.fontshare.com/licenses.

Both assets are served locally so the deployed interface does not need remote image or font requests at runtime.
